# Посібник адміністратора Kylymy

> Адреса адмінки: `https://kylymy.ua/admin/`
> Логін і пароль — надано окремо при передачі проєкту.

---

## 1. Додавання нового товару (серії)

### Крок 1. Відкрийте «Серії товарів»
Меню зліва → **Каталог** → **Серії товарів** → кнопка **«+ Додати серію»**

### Крок 2. Заповніть основні поля
| Поле                | Пояснення                                                         |
| ------------------- | ----------------------------------------------------------------- |
| **Розділ**          | Куди відноситься: Килими / Доріжки / Ковролін / Для ванної        |
| **Назва серії**     | Назва, як на сайті: "Shaggy Roco"                                  |
| **Slug (URL)**      | Генерується автоматично. Не міняйте без причини.                  |
| **Короткий опис**   | 1-2 речення для прев'ю                                             |
| **Повний опис**     | Детальний HTML-текст (редактор TinyMCE)                           |
| **Догляд**          | Інструкції по чищенню                                             |

### Крок 3. Класифікація (фасети)
Оберіть відповідні фасети з кожної групи:
- **Тип**: Високоворсний / Низьковорсний / Безворсовий...
- **Призначення**: У спальню / У вітальню / На кухню...
- **Стиль**: Сучасний / Класичний / Дитячий...
- **Форма**: Прямокутний / Овальний / Круглий...
- **Виробник**: Туреччина / Бельгія / Україна...

### Крок 4. Характеристики
Заповніть: Склад, Висота ворсу (мм), Матеріал основи, Країна.

### Крок 5. Маркетинг
- **Активний** — якщо вимкнено, товар не з'явиться на сайті
- **Топ** — виводиться у блоці "Популярні" на головній
- **Новинка** — виводиться у блоці "Новинки"
- **Знижка %** — встановіть відсоток знижки (наприклад, 15)

### Крок 6. Додайте варіанти (колір × розмір)
Прокрутіть вниз → блок **«Варіанти товарів»** → **+Додати варіант**:
- Артикул (SKU) — унікальний, наприклад: `SR-GREY-200300`
- Колір — обрати з випадайки
- Ширина (см) і Довжина (см)
- Ціна (грн) і Стара ціна (опційно)
- Прапорець "В наявності"

### Крок 7. Додайте фото
Блок **«Фото товарів»** → **+Додати фото** → завантажте файл.
- Позначте основне фото прапорцем "Головне фото"
- Порядок змінюється drag-and-drop полем "Порядок"

### Крок 8. SEO (опційно)
Поле **SEO Title** і **SEO Description** — залишіть порожніми якщо не знаєте що писати, система згенерує автоматично.

### Крок 9. Збережіть
Кнопка **«Зберегти»** внизу або вгорі сторінки.

## 2. Модерація відгуків

Меню → **Контент** → **Відгуки**

Тут видно всі відгуки. Ті, що не схвалені (прапорець "Схвалено" = ❌), не показуються на сайті.

**Як схвалити:**
1. Клікніть на відгук
2. Поставте прапорець **«Схвалено»**
3. Збережіть

**Масове схвалення:**
1. Відмітьте чекбоксами кілька відгуків
2. В дії (Action) оберіть **«Схвалити вибрані відгуки»**
3. «Виконати»

---

## 3. Перегляд і обробка замовлень

Меню → **Замовлення** → **Замовлення**

На кожному замовленні є:
- **Контакти** — ім'я, телефон, email
- **Доставка** — місто і відділення НП
- **Статус** — змінюйте у міру опрацювання

### Зміна статусу
| Статус          | Коли ставити                                 |
| --------------- | -------------------------------------------- |
| Нове            | Автоматично після оформлення                  |
| Підтверджено    | Після телефонного підтвердження               |
| Оплачено        | Після надходження оплати                      |
| Комплектується  | Збираєте товар для відправки                   |
| Відправлено     | Після здачі на Нову Пошту (введіть ТТН)       |
| Доставлено      | Клієнт отримав                                |
| Скасовано       | Клієнт відмовився                             |

---

## 4. Управління лідами (запити на дзвінок)

Меню → **Замовлення** → **Ліди / Дзвінки**

Список усіх запитів. Зателефонуйте і поставте прапорець **«Оброблено»**.

---

## 5. Редагування контенту

### Статті блогу
Меню → **Контент** → **Статті** → оберіть статтю або **«+ Додати»**

Редактор TinyMCE дозволяє:
- Форматувати текст (жирний, курсив, заголовки)
- Вставляти зображення
- Додавати посилання
- Вставляти списки

**Не забудьте** встановити прапорець **«Опубліковано»** і **«Дату публікації»** — інакше стаття не з'явиться на сайті.

### Сторінки (Доставка, Про нас тощо)
Меню → **Контент** → **Статичні сторінки**

---

## 6. Налаштування сайту

Меню → **Налаштування** → **Сайт**

Тут можна змінити:
- Телефон і email
- Графік роботи
- Посилання на соцмережі
- GTM ID (для аналітики Google)
- Мінімальна сума для безкоштовної доставки

---

## 7. Типові питання

**Де змінити телефон у шапці?**
Налаштування → Сайт → поле «Телефон для відображення»

**Як сховати товар з сайту (без видалення)?**
Серія товарів → зняти прапорець «Активний»

**Додав товар, але він не відображається?**
Перевірте що прапорець «Активний» встановлено і додано хоча б один варіант.

**Як зробити знижку?**
Серія товарів → поле «Знижка %» → вкажіть відсоток (напр. 15).
Варіанти → «Стара ціна» → вкажіть ціну до знижки.
