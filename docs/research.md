## Стислий висновок (TL;DR)

### Конкурент 1 — **dim-dim.com.ua**
- Чистий **сайт-вітрина на маркетплейсі Prom.ua** (`/ua/g{ID}-slug` — типовий патерн Prom).
- 6 категорій верхнього рівня, 1 рівень підкатегорій лише в "Килими та килимки" (10 серій-колекцій) і "Сучасні килими на гумовій основі" (4 серії).
- Картка товару — **багата характеристиками** (виробник, склад, форма, призначення, колір, розмір, висота ворсу, основа), але дизайн — стандартний шаблон Prom без брендингу.
- Унікальна сильна сторона: **продаж доріжок на відріз за погонним метром** (1.0 / 1.2 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0 м ширини × довжина клієнта).
- SEO — слабке: title зі стандартним хвостом "...в Дніпропетровській області від компанії Дім-Дім.ua", H1 = назва категорії без LSI, опис категорії відсутній майже всюди, URL не семантичний.

### Конкурент 2 — **kilimi.com.ua**
- **Власний движок**, мультимовність (`/uk/`, `/ru/`), ~10 000 SKU.
- **Багатовимірна таксономія**: 4 паралельні зрізи навігації:
  1. **Категорія** (Килими / Ковролін / Доріжки / Знижки)
  2. **Стиль** (європ.класика / східна класика / сучасні / вінтажні / етнічні / гобелени / шкіри / однотонні / шаггі тощо)
  3. **Призначення** (кухня / спальня / придверний / вітальня / дитяча / кабінет / прихожа)
  4. **Форма** (прямокутна / овальна / кругла / квадратна) і **Розмір** (~25 фіксованих сіток) і **Виробник** (15 країн)
- На сторінці категорії: **фільтр "Ціна за м²"** — це сильна фішка для килимів різних розмірів.
- На картці — список доступних розмірів із цінами (не один товар, а картка-серія).
- Контент: блоки "Переваги", "Характеристики", "Доставка" + **блог-статті**, **відгуки покупців**, FAQ.
- SEO — добре: title "Купити Килим Онлайн → Kilimi.com.ua", H1 без хвостів, є SEO-тексти на категоріях, є FAQ, відгуки, статті з внутрішньою перелінковкою.

### Що береться в kylymy
1. **Багатовимірна таксономія kilimi** + **гнучкість продажу за пог.м dim-dim** = унікальна перевага.
2. **SEO-каркас**: фасетні сторінки індексуються (вибрані комбінації), title/description через шаблон, JSON-LD на всі типи сторінок, повна i18n із hreflang.
3. **Картка-серія** (одна модель — багато розмірів і кольорів у swatch-перемикачі), як у kilimi, але з рендером характеристик як у dim-dim.
4. **HTMX-фільтр** без перезавантаження сторінки, з push-state для індексації Google.
5. **Mobile-first**: iOS Safari (safe-area-inset, 100dvh, no-tap-highlight, sticky filter button).
6. **Контент**: відгуки під товаром і на головній, блог із внутрішньою перелінковкою на категорії та товари.

## Карта сайту kylymy (верхній рівень)

```text
/                                  # Головна
/uk/                               # Підготовлено для i18n (наразі редирект → /)
/kylymy/                           # Каталог килимів
  └─ /<style>/                     # /shaggy/, /klasychni/, /suchasni/...
  └─ /<purpose>/                   # /dlya-spalni/, /dlya-vitalni/...
  └─ /<shape>/                     # /ovalni/, /kruhli/...
  └─ /<size>/                      # /160x230/, /200x300/...
/dorizhky/                         # Доріжки (на відріз і фіксовані)
/kovrolin/                         # Ковролін
/dlya-vannoyi/                     # Килимки для ванної
/akciyi/                           # Знижки
/blog/                             # Статті
  └─ /<slug>/
/dostavka-i-oplata/
/pro-nas/
/kontakty/
/garantiyi-i-povernennya/
/yak-vybraty-kylym/                # SEO-лендинг гайд
/dohlyad-za-kylymom/               # SEO-лендинг гайд
```
