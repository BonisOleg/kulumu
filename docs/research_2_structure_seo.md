# Research · Частина 2 · Структура сайту kylymy + SEO-стратегія

> Власна інформаційна архітектура: таксономія, URL-патерни (i18n-ready), SEO-шаблони (title / description / H1 / H2), schema.org, sitemap, перелінковка.

---

## 1. Принципи побудови

1. **Семантика > колекції виробника.** Клієнт шукає "килим у спальню сірий 200х300", а не "Lux Shaggy 6365A". Колекція — лише фасет, а не верхній рівень.
2. **Картка-серія, варіанти всередині.** 1 модель = 1 URL = багато кольорів/розмірів як варіанти.
3. **Багатовимірний фасет з індексованим whitelist.** Не індексуємо все підряд (колінні комбінації × колір × ціна тощо), а вибірково публікуємо як SEO-сторінки топ-комбінації.
4. **i18n-ready з першого дня.** Префікс `/uk/` (default) і `/en/` як приклад. URL slug перекладається через `prepopulated_fields` + поле `slug_uk`, `slug_en` у моделі.
5. **Mobile-first SEO.** Core Web Vitals як архітектурний пріоритет: SSR через Django + кешування + критичний CSS inline + лазі-зображення.
6. **Контент, а не лише товари.** Блог + гайди + FAQ + відгуки = довгий хвіст і авторитет.

## 3. URL-структура (повна, i18n-ready)

### 3.1 Принцип

```
/{lang}/{section}/{facet1-slug}/{facet2-slug}/?{filter_params}
```

- `{lang}` = `uk` (default, можна без префіксу) / `en` / `ru`
- `{section}` = одна з 5 (`kylymy`, `dorizhky`, `kovrolin`, `dlya-vannoyi`, `akciyi`)
- `{facet1-slug}` і `{facet2-slug}` — З WHITELIST (комбінації, які ми хочемо індексувати), решта — query-параметри
- `?` — несемантичні фільтри (ціна, виробник, колір якщо не топ)

### 3.2 Whitelist-комбінації (ті, що мають свою URL і індексуються)

| Шаблон                              | Приклад                             | Тип сторінки           |
| ----------------------------------- | ----------------------------------- | ---------------------- |
| `/<section>/`                       | `/kylymy/`                          | Корінь розділу          |
| `/<section>/<facet>/`               | `/kylymy/vysokovorsni/`             | 1-вимірна (тип / стиль / призначення / форма / розмір / колір / виробник) |
| `/<section>/<facet>/<size>/`        | `/kylymy/dlya-spalni/2.0x3.0/`      | 2-вимірна: призначення + розмір (ТОП-100 комбінацій) |
| `/<section>/<facet>/<color>/`       | `/kylymy/suchasni/sirij/`           | 2-вимірна: стиль + колір (ТОП-50) |
| `/<section>/<facet>/<form>/`        | `/kylymy/dlya-spalni/kruhli/`       | 2-вимірна: призначення + форма (ТОП-30) |
| `/<section>/seriya/<series-slug>/`  | `/kylymy/seriya/shaggy-roco/`       | Сторінка серії          |
| `/<section>/<series-slug>/<sku-slug>/` | `/kylymy/shaggy-roco/grafit-2x3/` | Картка товару (варіант) — або /shaggy-roco/ без розміру + варіанти на сторінці |
| `/<section>/akciyi/`                | `/kylymy/akciyi/`                   | Акційні товари в розділі |
| `/akciyi/`                          | `/akciyi/`                          | Усі акції               |
| `/blog/`                            | `/blog/`                            | Блог-індекс             |
| `/blog/<article-slug>/`             | `/blog/yak-vybraty-kylym-u-spalnyu/`| Стаття                  |
| `/blog/category/<cat-slug>/`        | `/blog/category/dohlyad/`           | Рубрика блогу           |

### 3.3 Технічні URL (`noindex,follow`)
- `/<section>/?cena=1000-3000&color=blue` — будь-який query-фільтр
- `/<section>/<facet>/?sort=price-asc&page=2`
- `/search/?q=...`
- `/profile/`, `/cart/`, `/checkout/`
- Усе під `/admin/`

### 3.4 Канонічні URL
- На фасетних сторінках: `<link rel="canonical" href="/<section>/<facet>/">` (без query)
- На картці товару: `<link rel="canonical" href="/<section>/<series-slug>/">` (єдиний URL для серії)
- На пагінації (`?page=2`) — canonical вказує на ту ж саму URL з `?page=2`, плюс `<link rel="prev/next">` (deprecated, але не зашкодить)

### 3.5 hreflang
На кожній сторінці:
```html
<link rel="alternate" hreflang="uk" href="https://kylymy.ua/uk/kylymy/vysokovorsni/">
<link rel="alternate" hreflang="ru" href="https://kylymy.ua/ru/kovry/vysokovorsnye/">
<link rel="alternate" hreflang="x-default" href="https://kylymy.ua/uk/kylymy/vysokovorsni/">
```

### 4.5 sitemap.xml

Розбиття на index + 4 індексованих файли:
- `sitemap_index.xml`
- `sitemap_pages.xml` — статичні сторінки (Доставка, Контакти, Про нас, FAQ, лендинги)

## 5. Перелінковка (внутрішня)

### 5.1 Глобальні елементи
- **Header**: лого + 5 розділів + пошук + кошик + лідогенерація (телефон-CTA)
- **Mega-menu** (десктоп): на ховері кожного розділу — 4 колонки фасетів (тип / призначення / стиль / форма+розмір)
- **Mobile-menu** (drawer): акордеон 5 розділів → фасети
- **Footer**: 4 колонки — Каталог / Інформація / Сервіс / Контакти + 30 топ-фасетних посилань

### 5.2 Хлібні крихти
На КОЖНІЙ сторінці (крім головної) із Schema.org BreadcrumbList. Крихти показують реальний шлях, навіть для фасетних:
`Головна → Килими → Високоворсні → 2.0×3.0`

### 5.3 Блоки на картці товару (внизу)
1. **Доступні розміри** (як у kilimi)
2. **Інші кольори цієї серії** (свотчі)
3. **Схожі моделі** (3-6 із того ж фасету: тип + призначення + ціновий діапазон ±30%)
4. **З цим купують** (підкладка під килим, чистячий засіб)
5. **Ви дивилися нещодавно** (cookie/session)
6. **Статті у блозі за темою** (ручний tagging або по фасету)

### 5.4 Блоки на фасетних сторінках
- Внизу — **сусідні фасети** ("Дивіться також: круглі килими, килими 2×3, килими сірі") — горизонтальний блок
- Внизу — **рекомендовані статті** з блогу
- На правій колонці (десктоп) — топ-3 акційні товари

### 5.5 Блоги ↔ товари
- Кожна стаття має 5-15 in-text посилань на категорії і конкретні товари (як у kilimi: "[shaggy](http://...)")
- У кінці кожної статті — блок "Підбірка товарів за темою" — 6 карток
